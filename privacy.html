Політика конфіденційності

Чернетка для тестового запуску. Документ буде уточнюватися.

Цей документ описує, які дані можуть оброблятися під час тестового використання сайту Pandora / U.S.E.N. Формулювання є робочими і не замінюють фінальний юридичний документ.

Які дані можуть збиратися

Сайт може отримувати дані, які користувач сам вводить у форми: ім’я, email, телефон, країну, месенджери, текст звернення, коментарі та дані заявки. Також можуть оброблятися технічні дані браузера, необхідні для роботи сайту, безпеки та запобігання спаму.

Цілі обробки

  • зворотний зв’язок з користувачем;
  • обробка заявки або звернення;
  • комунікація з учасником проєкту;
  • покращення сайту та користувацького досвіду;
  • безпека та запобігання спаму.

Передача даних

Дані не продаються третім особам. Для надсилання форм можуть використовуватися зовнішні сервіси обробки заявок і повідомлень. Такі сервіси отримують лише дані, необхідні для доставки звернення.

Права користувача

Користувач може запросити уточнення, виправлення або видалення своїх даних, якщо це технічно можливо в межах поточного етапу проєкту. Для звернення використовуйте email: usenpandora@gmail.com.

Строк зберігання

Дані зберігаються стільки, скільки необхідно для обробки звернення, тестування сайту, підготовки документів проєкту та виконання розумних організаційних завдань.

Cookies і локальне сховище

Сайт може використовувати localStorage для збереження вибраної мови інтерфейсу та користувацьких налаштувань. Це допомагає відновити вибрану мову при повторному відкритті сайту.

Политика конфиденциальности

Этот документ описывает, какие данные могут обрабатываться при тестовом использовании сайта Pandora / U.S.E.N. Формулировки являются рабочими и не заменяют финальный юридический документ.

Какие данные могут собираться

Сайт может получать данные, которые пользователь сам вводит в формы: имя, email, телефон, страну, мессенджеры, текст обращения, комментарии и данные заявки. Также могут обрабатываться технические данные браузера, необходимые для работы сайта, безопасности и предотвращения спама.

Цели обработки

  • обратная связь с пользователем;
  • обработка заявки или обращения;
  • коммуникация с участником проекта;
  • улучшение сайта и пользовательского опыта;
  • безопасность и предотвращение спама.

Передача данных

Данные не продаются третьим лицам. Для отправки форм могут использоваться внешние сервисы обработки заявок и сообщений. Такие сервисы получают только данные, необходимые для доставки обращения.

Права пользователя

Пользователь может запросить уточнение, исправление или удаление своих данных, если это технически возможно в рамках текущего этапа проекта. Для обращения используйте email: usenpandora@gmail.com.

Срок хранения

Данные хранятся столько, сколько необходимо для обработки обращения, тестирования сайта, подготовки документов проекта и выполнения разумных организационных задач.

Cookies и локальное хранилище

Сайт может использовать localStorage для сохранения выбранного языка интерфейса и пользовательских настроек. Это помогает восстановить выбранный язык при повторном открытии сайта.

Privacy Policy

Draft for the test launch. The document will be clarified.

This document describes what data may be processed during test use of the Pandora / U.S.E.N. website. The wording is provisional and does not replace the final legal document.

What data may be collected

The website may receive data that the user enters into forms: name, email, phone number, country, messengers, message text, comments and application data. Technical browser data required for website operation, security and spam prevention may also be processed.

Purposes of processing

  • feedback and communication with the user;
  • processing an application or request;
  • communication with a project participant;
  • improving the website and user experience;
  • security and spam prevention.

Data transfer

Data is not sold to third parties. External services may be used to process forms and messages. Such services receive only the data required to deliver the request.

User rights

The user may request clarification, correction or deletion of their data if this is technically possible at the current stage of the project. Use this email for requests: usenpandora@gmail.com.

Storage period

Data is stored for as long as necessary to process the request, test the website, prepare project documents and perform reasonable organisational tasks.

Cookies and local storage

The website may use localStorage to save the selected interface language and user settings. This helps restore the selected language when the website is opened again.

Contact

For privacy questions: usenpandora@gmail.com.

Política de privacidad

Borrador para el lanzamiento de prueba. El documento será precisado.

Este documento describe qué datos pueden procesarse durante el uso de prueba del sitio Pandora / U.S.E.N. Las formulaciones son provisionales y no sustituyen el documento legal final.

Qué datos pueden recopilarse

El sitio puede recibir los datos que el usuario introduce en los formularios: nombre, email, teléfono, país, mensajeros, texto del mensaje, comentarios y datos de la solicitud. También pueden procesarse datos técnicos del navegador necesarios para el funcionamiento del sitio, la seguridad y la prevención del spam.

Finalidades del tratamiento

  • comunicación con el usuario;
  • procesamiento de una solicitud o mensaje;
  • comunicación con un participante del proyecto;
  • mejora del sitio y de la experiencia del usuario;
  • seguridad y prevención del spam.

Transferencia de datos

Los datos no se venden a terceros. Para enviar formularios pueden utilizarse servicios externos de procesamiento de solicitudes y mensajes. Estos servicios reciben solo los datos necesarios para entregar el mensaje.

Derechos del usuario

El usuario puede solicitar la aclaración, corrección o eliminación de sus datos si esto es técnicamente posible en la etapa actual del proyecto. Para consultas, use el email: usenpandora@gmail.com.

Periodo de almacenamiento

Los datos se conservan durante el tiempo necesario para procesar la solicitud, probar el sitio, preparar documentos del proyecto y realizar tareas organizativas razonables.

Cookies y almacenamiento local

El sitio puede usar localStorage para guardar el idioma seleccionado de la interfaz y la configuración del usuario. Esto ayuda a restaurar el idioma elegido al volver a abrir el sitio.

Contacto

Para cuestiones de privacidad: usenpandora@gmail.com.
